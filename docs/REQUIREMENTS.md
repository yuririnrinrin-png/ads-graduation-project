# 要件・合意事項（Grill 結果）

このドキュメントは、設計インタビュー（Grill）で確定した内容の記録です。実装・変更時はここを正とします。

## 1. ゴール

| 項目 | 決定 |
|---|---|
| 利用者 | 自社 EC の担当者 |
| 成功の定義 | ほぼそのまま商品ページに載せられる品質。1 商品あたり数分 |
| 提供形態 | 社内向けブラウザ Web アプリ |
| 認証 | 共有の社内ログイン（ID/パスワード or Google）。人ごとの細かい権限は v1 対象外 |

## 2. 対象商品

| 項目 | 決定 |
|---|---|
| スコープ | 全カテゴリ対応（部位ルールはカテゴリで差し替え） |
| v1 の選択一覧 | **ネックレス**（ペンダント・チョーカー含む）／**ピアス・イヤリング**／**リング**／**ブレスレット** |
| 10 枚の型 | 役割（ディテール3／着用4／全身2／引き+インセット1）は共通。写す部位だけ変える |

### カテゴリ別の部位（着用シーン）

| カテゴリ | 着用 4 枚で主に写す部位 |
|---|---|
| ネックレス | 胸元〜顔（バストアップ） |
| ピアス・イヤリング | 顔まわり |
| リング | 手元 |
| ブレスレット | 腕まわり |

シーン名（オフィス／カフェ／デート／休日）は全カテゴリ共通。

## 3. 入力

| 項目 | 決定 |
|---|---|
| 枚数 | 同一商品の角度違い **3 枚** |
| 撮影条件 | 白〜淡色背景。商品のみがはっきり写っていること |
| カテゴリ | アップロード時に担当が手動選択 |
| 地金カラー | アップロード時に選択。表示は **YG / WG / PG**（PG＝ピンクゴールド。RG 表記は使わない） |
| メイン写真 | 3 枚のうち 1 枚を選択。着用合成のソースに使う |
| 対応関係 | 3 枚 → ディテール 3 枚にそのまま対応（背景差し替え）。着用 7 枚はメイン写真を軸 |

## 4. プリセット・見た目の選択

| 項目 | 決定 |
|---|---|
| 人物 | ブランド用プリセットから商品ごとに 1 人選ぶ。**1 ジョブ内は同一人物**（枠の再生成でも人物は維持） |
| ディテール背景 | プリセットから 1 つ選び、ディテール 3 枚で統一 |
| 全身トーン | 4 択から **2 つ**選ぶ。服の細部は AI 任せ |
| 初期プリセット数 | 人物 **3**・背景 **4**・全身トーン **4**。あとから管理側で追加可能 |

背景プリセット例: 白大理石／トラバーチン／リネン／黒石  
全身トーン例: オフィス／休日／エレガント／リラックス

## 5. 生成品質・合成方針

| 項目 | 決定 |
|---|---|
| ディテール 3 枚 | AI 人物生成なし。切り抜き＋背景差し替え＋地金に合わせた色調整のみ |
| 着用・全身・引き | 人物は AI 生成。**商品はアップロード実物を切り抜いて合成**（AI にジュエリーを描かせない） |
| 配置 | まず自動配置。プレビューで**大きさ・位置**だけつまみ調整 |
| レビュー | 10 枚一覧 → **ダメな枠だけ再生成** → ZIP ダウンロード |
| インセット 1 枚 | 引き＝全身をもう 1 枚生成。右下インセット＝ディテールから担当が選択 |

## 6. 出力

| 項目 | 決定 |
|---|---|
| 形式 | 役割つきファイル名の **ZIP**（EC への自動アップロードは v1 対象外） |
| 比率・解像度 | すべて **1:1・2000×2000** |
| 保管 | 生成結果は **14 日で削除**。ZIP はダウンロード時に打包 |

### ZIP ファイル名

```
01_detail_a.jpg
02_detail_b.jpg
03_detail_c.jpg
04_wear_office.jpg
05_wear_cafe.jpg
06_wear_date.jpg
07_wear_holiday.jpg
08_body_tone1.jpg
09_body_tone2.jpg
10_wide_inset.jpg
```

## 7. 待ち時間・エラー

| 項目 | 決定 |
|---|---|
| 初回生成 | **2〜4 分**（進捗表示あり） |
| 単枠再生成 | 数十秒〜1 分目安 |
| 失敗時 | 段階名つきで失敗表示。最初から／失敗段階からリトライ可 |

進捗段階: `切り抜き → ディテール → 人物シーン → 合成 → 仕上げ`

## 8. v1 でやらないこと

- EC（Shopify 等）への自動アップロード  
- ユーザー個別の RBAC・詳細監査ログ  
- カテゴリの細分化（フープピアス、スタックリング等）  
- 印刷向け超高解像度（3000px 超）  
- ログインなしの公開 URL  

## 9. 未決（実装時に詰める）

- 画像生成 API／切り抜きモデルの最終ベンダーと 1 商品あたりコスト  
- ホスティング先の本番構成  
- 人物・背景プリセットの中身（実デザイン・プロンプト）  
- 商品ページ側で「AI モデル使用」等の表記が要るか（ツール外方針含む）
