- **胴体は正面±15°。** 顔は斜め・横向きを7枚のうち数枚入れる。後ろ姿・肩越し禁止。
- **7枠の表情はすべて別**（`SLOT_EXPRESSION`）。目線は伏し目・外し目・柔らかい正面を混ぜる。

- **髪型:** アップと耳かけダウンの両方（ダウンはカフェと引き）。
- **服:** 首元開きとタートルを混在。
- **リング／ブレス着用4枚:** 手首／指が主役。顔は奥か端。
- **全身・引き:** 立ち姿。手首／指はフレーム内。**腕組み禁止。**
- モデル（男性含む）に **時計・他のジュエリーを描かせない。**
- 大きなズレはレビューのドラッグ／回転で救う。
- ピアスは片耳分3枚 → 両耳へ鏡写し。横顔では片方を消せる（`SlotTransform.hidden`）。

## この期間の実装（品質まわり）

### なぜプロンプトだけだと足りないか

PuLID は参照顔（正面・髪ダウン）を強くコピーする。プロンプト検査（フック）が OK でも画像は仕様外れになりうる。

### 機械チェック（2段）

1. **プロンプト:** `.cursor/hooks/check_scene_spec.py`  
   - Cursor フック: `.cursor/hooks.json`（`afterFileEdit` on `scene_gen.py`、`stop` で最大3回追い返し）
   - ルール: `.cursor/rules/scene-persona.mdc`
   - CLI: `apps/worker/.venv/Scripts/python.exe .cursor/hooks/check_scene_spec.py`
2. **生成後画像:** `apps/worker/worker/scene_qa.py`（YuNet の顔枠・目の幅）
   - リング／ブレス着用: 顔が大きすぎ／中央すぎ → やり直し
   - 全身: 顔が低すぎ（腕組みバストアップ疑い）→ やり直し
   - 斜め枠: 顔が証明写真すぎ → やり直し
   - デート: 最大の顔が右下（男性手前）／女性の顔が小さすぎ → やり直し
   - PuLID を最大3回。全部落ちたら **`fal-ai/flux/dev` フォールバック**（顔が別人寄りになりうる。不合格画像をそのまま採用しない）

測れないもの（プロンプト頼み）: 表情7種、髪アップ／ダウン、タートル、時計の画素検出。

### デートで男性が手前になった理由

「男性のぼかした手元」と書いた＋ `id_weight` を下げすぎ（0.14）。モデルが男性の腕を主役にした。  
いま: 女性が sharp foreground、男性は BACKGROUND。`id_weight=0.20`。男性の手前手元は禁止。

### 全身が全部腕組みになった理由

PuLID が同じ bust をコピー。QA は正面を3回落としていたが **最後の不合格を採用**していた。  
いま: 枠ごとに腕の位置を分ける。腕組みネガティブ。顔の Y 位置で bust を落とす。3回後は flux/dev。

### その他直したこと

- 手元プロンプト短縮（512トークン対策）。オフィスに PC を出さない。
- ブレス「like showing a watch」削除（時計を描かせていた）。
- 参照顔クロップを狭く（髪型コピーを弱める）。
- `face_anchor.detect_faces_detail`（yaw の目安）。
- `TRANSFORM_ROTATE_LIMIT = 180` は前コミット済み。

主なファイル: `scene_gen.py`, `scene_qa.py`, `face_anchor.py`, `pipeline.py`（起動ログ）。

PuLID 手カテゴリ: `id_weight=0.18`。`start_step` 禁止。

## 技術メモ

- 配置の正: `packages/shared/src/index.ts` の `CATEGORY_ANCHORS` / `BODY_ANCHORS`。`pipeline.py` と必ず同じ。
- 実座標: `SIZE * anchor.x + transform.offsetX`（`SIZE = 2000`）。
- 顔検出配置: ネックレス／ピアスのみ。リング／ブレスは固定アンカー＋ドラッグ。
- 再生成は `persona_ref.jpg` を再利用。
- ワーカー停止中のジョブは Redis から消え、DB が `running` のままだとリトライ 409。
- 画面とワーカーを同じターミナルにしない。ワーカーは同時に1つ。
